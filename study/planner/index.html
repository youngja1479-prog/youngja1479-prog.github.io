      홈 화면 앱 설치

      PWA

      설치하면 주소창 없이 앱처럼 열리고, 비행기 모드에서도 기록이 열립니다.

      버튼이 설치 창을 안 열면 크롬에서 ⋮ → 앱 설치(또는 홈 화면에 추가)를 눌러 주세요. 이미 설치했다면 홈 화면의 스터디 플래너 아이콘으로 열면 됩니다.

      동기화 (선택)

      꺼짐

      기기 간 동기화는 플래너 전용 키로 암호화해 저장합니다. 목차 학습 노트의 동기화 데이터와는 키가 완전히 분리되어 서로 덮어쓰지 않습니다.

      같은 동기화 코드를 피자에게 알려두면, 피자가 이 기록을 직접 읽고 코칭할 수 있어요.
