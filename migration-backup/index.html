기기 데이터 백업

휴대폰·태블릿에서 공부/게임 진행 기록을 파일로 저장하거나 불러오기합니다. 개발자 도구는 필요 없습니다.

이 페이지는 브라우저에만 저장된 데이터를 다룹니다. 동기화 비밀번호·초대 링크·세션은 백업에 넣지 않습니다. 노트 클라우드 동기화는 새 주소에서 비밀번호를 다시 입력해야 할 수 있습니다. 백업 파일은 채팅/클라우드에 올리지 말고 이 기기에 보관하세요.

1. 백업 파일 저장

목차 노트(필기·이미지 포함), 영단어, 게임 점수 등 이 사이트 주소에 저장된 기록을 모읍니다.

2. 백업 파일 불러오기

기본은 비어 있는 항목만 채웁니다. 이미 있는 데이터는 덮어쓰지 않습니다.

공개 사이트와 새 비공개 주소는 저장 공간이 다릅니다. 공개 사이트에서 저장 → 새 주소에서 불러오기 순서로 하세요.
